# KNOPKA - Система рекомендаций фильмов

**KNOPKA** - это веб-приложение для рекомендаций фильмов, предназначенное для предоставления пользователям персонализированных предложений фильмов, управления их списками просмотра и изучения популярных фильмов. Система объединяет серверную часть, работающую на Flask, и интерфейс с динамическим рендерингом JavaScript, обеспечивая интуитивно понятный и плавный пользовательский опыт.

---

## **Особенности**

1. **Аутентификация пользователя**:
   - Регистрация пользователя и вход в систему с помощью безопасной аутентификации на основе JWT.

2. **Рекомендации по фильмам.**:
   - Персонализированные рекомендации на основе предпочтений пользователя с использованием предварительно обученной модели KNN.

3. **Функциональность поиска**:
   - Поиск фильмов по названию и динамический просмотр результатов поиска.

4. **Управление избранным.**:
   - Добавляйте фильмы в список избранного для быстрого доступа.

5. **История просмотра**:
   - Просматривайте записи просмотренных фильмов.

6. **Динамический контент**:
   - Просматривайте рекомендуемые фильмы или ищите их на лету.

## **Installation**

### 1. Клонируйте репозиторий
```bash
git clone https://github.com/akinara666/knopka.git
cd knopka
```

### 2. Настройте виртуальную среду
```bash
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
```
### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 4. Запустите приложение
Start the Flask development server:

```bash
flask run
```
Приложение будет доступно по адресу http://127.0.0.1:5000.
